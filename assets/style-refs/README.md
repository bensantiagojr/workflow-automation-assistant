# Style reference images

`generate_images.py` sends up to 5 images from one of these folders with every request so generated art keeps the same look. The OpenAI API has no memory between calls, so these replace the ChatGPT thread.

- `por-pointillism/`: 3 to 5 approved pointillism images (the email header icons work well).
- `r360-illustration/`: add once a Record360 illustration style is approved.

Use PNG, JPG or WebP, under about 2 MB each. Only approved, on-brand images, and nothing with logos or readable text.
