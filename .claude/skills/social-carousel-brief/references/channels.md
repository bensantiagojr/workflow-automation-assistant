# Channels and formats

## Where each post type goes
| Brand | Post type | Channels |
|---|---|---|
| Point of Rental | Video or Reel | YouTube (Shorts), Facebook, Instagram, LinkedIn, X, Threads |
| Point of Rental | Carousel or image post | Facebook, Instagram, LinkedIn, X, Threads (not YouTube) |
| Record360 | Any | Instagram, Facebook, LinkedIn |

Data note: Threads returned about 1,000 impressions from 116 posts and YouTube Shorts are 0.5% of channel traffic. Cross-post them only when it costs no extra work.

## Export set for a carousel
- Slides: 1080 x 1350 px (4:5), PNG.
- LinkedIn: the same slides combined into one PDF document, cover first.
- Instagram, Facebook, Threads: the PNG set.
- X: cover plus three slides (4 image limit), with its own shorter caption.

## Caption rules per channel
| Channel | Length | Notes |
|---|---|---|
| LinkedIn | 600 to 1,200 characters | Only the first ~140 characters show before "...more". That first line must add new information, not repeat slide 1. Test the link in the first comment vs the body (see playbook T2). |
| Facebook | 200 to 500 characters | Short. Link allowed in the post. |
| Instagram | 150 to 400 characters | Captions are not clickable. Say "link in bio" and use the tagged link on the bio or Linktree. |
| X | 280 characters max | Cover plus three slides. Link in the post. |
| Threads | 300 characters max | Same text as X, lightly adjusted. |
| YouTube | Video only | Title written for search, since half the traffic comes from search. |

## Caption rules for all channels
- First line adds information the slide does not say.
- Do not reuse the same emoji or opener on every post.
- Hashtags: 2 to 3 relevant ones at most, none on X and Threads.
- State the link once. No "click the link below" filler.
