# Record360 illustration style (proposed, confirm before first use)

No illustration style has been approved for Record360 yet. The current samples use AI photographs, which should not be used for damage or proof (see `voice-r360.md`). Proposal for the first test:

> Clean flat editorial illustration in a navy and red palette with white highlights, simple geometric shapes, thick consistent outlines, a vehicle or piece of equipment drawn as a simple object with one marked area of interest. Abstract interface cards with no readable text. No words, no numbers, no logos, no photorealism.

## How to use it
- Illustration tells the story ("a return inspection with one flagged area"). Real photos and real app screenshots carry the proof.
- Add 3 to 5 approved reference images in `assets/style-refs/r360-illustration/` once the style is chosen. Palette values come from the Record360 design system.
- Keep a visible "Illustration" note in the layout or caption when a scene stands in for a real capture.

## Prompt skeleton
```
{STYLE PARAGRAPH}

Show {ELEMENTS}. {COMPOSITION}. {BACKGROUND}.
```
